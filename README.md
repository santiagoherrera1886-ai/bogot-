# Bogotá Mobility Lab 2040

Aplicación React/TypeScript/Vite para explorar escenarios hipotéticos de movilidad de Bogotá y Sabana.

## Ejecutar

```bash
npm install
npm run dev
```

## Desplegar en Vercel

Framework: Vite. Build: `npm run build`. Output: `dist`.

## Advertencia de datos

No contiene tráfico en tiempo real. Corredores aproximados, velocidades, costos, proyecciones y efectos de intervención son supuestos sintéticos; no son recomendaciones de ingeniería. Los escenarios se conservan solamente durante la sesión.

Fuentes futuras: Observatorio de Movilidad de Bogotá, IDECA y datos abiertos SDM.
